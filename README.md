# Meta-Learning Performance Analyzer (Advanced Research Version)

![Python](https://img.shields.io/badge/python-3.9%2B-blue)
![Machine Learning](https://img.shields.io/badge/Machine%20Learning-Meta--Learning-brightgreen)

## Overview
A meta-learning-based intelligent framework to:
- Predict the performance of ML models
- Recommend optimal algorithms
- Quantify dataset difficulty
- Benchmark against AutoML systems
- Enhance prediction using neural meta-learning (MLP)

## Folder Structure
- `data/`: Raw, processed and meta-datasets.
- `notebooks/`: Exploratory Data Analysis and experimentation.
- `src/`: Core Python modules (Preprocessing, Extraction, Models, Meta-Learning, etc.)
- `configs/`: YAML configuration files.
- `outputs/`: Saved models, reports, and visualization plots.

## Installation
```bash
pip install -r requirements.txt
```

## Running the Pipeline
Execute the main script to run the full pipeline:
```bash
python main.py
```
